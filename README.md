# Abhay Raj – Resume Website (React + Vite)

    npm install
    npm run dev      # local dev
    npm run build    # production build in dist/

All content lives in `src/config/*.json` — edit those, no code changes needed:
profile, navigation, skills, experience, education, awards, theme.
Drop your resume PDF into `public/` as `AbhayRaj_Architect_SSE_Resume.pdf` for the Resume button.
